    Notes

    1. Google OAuth client

    This app needs an OAuth client from your own Google Cloud project — a small JSON file you download once. This step can't be automated from in here (there's no bootstrap credential to call Google's own APIs with), but uploading the resulting file can be.

    1. Create a project. In the Google Cloud Console, create a project (or reuse one you already have) and enable the Calendar, Gmail, Sheets, and Drive APIs.
    2. Add yourself as a test user. Under "APIs & Services → OAuth consent screen", add the Google account(s) you'll sign in with under Test users — including your own.
    3. Create the OAuth client. Under "APIs & Services → Credentials", create an OAuth client ID of type Desktop app, and download its JSON.
    4. Upload that JSON file below.
    Skipped step 2? You'll see "Access blocked" / Error 403 when connecting below. Go back and add your account as a Test user.

    Checking…

    2. Connect your account

    One connection covers Calendar, Gmail (read-only search + draft creation, never send), Sheets, and Drive. See CLAUDE.md for exactly what is and isn't allowed with it (no sending email, no calendar invites, no editing files it didn't create).

    "Access blocked" / Error 403 here? The signed-in account isn't on the Test users list yet — go back to step 1 and add it.
