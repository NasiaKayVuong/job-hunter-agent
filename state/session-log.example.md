# Session log

Read this first, every session — it's the only memory of what happened in
previous ones. A fresh Claude Code session (new window, new day, different
machine) has zero recollection of past conversations; this file is how it
catches up. Append a new dated entry after any significant work (a search,
a batch of drafts, a status sync) — never rewrite or delete prior entries,
same discipline as a changelog. Keep entries short: what happened, what's
pending, what the user should know. Full detail already lives in the right
place (`applications/log.md` for search/apply detail, the tracker/listings
Sheet for data) — this file is the narrative thread connecting sessions, not
a duplicate of either.
